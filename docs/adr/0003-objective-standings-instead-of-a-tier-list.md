# 以客觀賽事統計取代主觀 Tier 榜

新站沒有社群公信力可以支撐「這支是 S 級」這種主觀宣稱，而主觀榜單還需要持續投入判斷、會被質疑、過期就砸招牌。因此本站不發布 Tier List，改為從實際 Event 結果統計出 Meta Standing——使用率、前八強佔比、奪冠次數——並強制附上 Sample Size 與統計期間。

## Consequences

- 榜單隨賽事資料自動更新，不需人工重排。
- 質疑只能針對資料正確性，而那是可查證的；不會演變成無法收斂的品味爭論。
- 此決策完全押在賽事資料的可得性與品質上。開工第一件事必須先驗證實際樣本量；若資料撐不住，退路是「客觀統計為主榜 + 玩家評價為輔」。
- 樣本不足時必須顯示「資料不足」而非勉強排名。誠實的空白比虛假的名次更能建立信任。

## 驗證結果（03 號票，賽事資料 spike）

實測 hackmd 上唯一的彙總試算表「陀螺賽場統計2025」：1215 筆配招紀錄、261 位玩家，時間涵蓋 2025 年 1–10 月，使用率資料紮實。但**名次欄位全年只有 4 列有填值，等於只有一場賽事留下完整名次**——前八強佔比、奪冠次數目前完全撐不住統計意義（n=1）。另一批「Funbox 門市月度時間表」試算表純屬賽事排程，不含賽果。

**維持本 ADR 不變，不退回主觀評價路線**——設計本身的 Sample Size 門檻與「資料不足」顯示，正是為了應付這種情況而存在，不是失敗後才想到的補救。真正該調整的是落地預期：第一版上線時，使用率會有真實數字，但前八強佔比與奪冠次數幾乎每一筆都會顯示「資料不足」，這是資料現況、不是實作缺陷。完整分析見 [03 號票](../../.scratch/oldbabyinfo/issues/03-tournament-data-spike.md)。
