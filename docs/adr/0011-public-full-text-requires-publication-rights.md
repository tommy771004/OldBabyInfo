# 公開全文必須具有 Publication Rights

OldBabyInfo 可以在 repo 靜態資料中保存並於網站公開來源全文，但只限具相容公開授權，或權利人已明確同意自動取得與公開重刊的內容。沒有 Publication Rights 的來源只能產出結構化事實、必要短片段與原文連結，不能因為頁面公開可讀就鏡像全文或圖片。

## Consequences

- 第一版維持完全非商業：不放廣告、聯盟導購或付費功能，以保持與 CC BY-NC 等非商業授權相容。未來若要營利，必須先移除或重新取得所有 NC 內容授權。
- 每個全文來源必須記錄授權名稱、授權頁面或許可證明，以及擷取時適用的授權版本。
- 來源條款禁止自動大量抓取時，即使內容授權允許非商業轉載，也必須改用站方同意的取得方式或手動匯入。
- 授權撤回或變得不相容時，公開全文必須能從建置輸出中移除；已抽取的結構化事實另依其性質重新判斷。
