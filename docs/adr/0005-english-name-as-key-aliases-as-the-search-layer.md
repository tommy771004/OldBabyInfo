# 零件主鍵採官方英文名，多語與俗稱走 Alias 層

同一支零件在台灣現場至少有四個名字：官方英文、日文原名、不一致的中文譯名、以及玩家口語俗稱；而使用者搜尋時打的往往是最後一種。因此 Part 的主鍵與網址 slug 採 TAKARA TOMY 官方英文名（唯一無歧義、對得上官方應用程式與賽事登記），三語名稱各存一欄，其餘一切寫法收進 Alias 供搜尋命中。

## Consequences

- 主鍵選 TAKARA TOMY 而非 Hasbro 命名，因為台灣流通的是日版。Hasbro 名稱一律收進 Alias。
- 中文名取自台灣社群既有的通行用語，不自創翻譯——使用者搜尋的就是那些既有詞彙。
- 介面語言可在 zh-TW / ja / en 之間切換，但搜尋永遠跨語言全命中，不受當前介面語言限制。
- 三語並列僅出現在 Part 詳情頁；列表與比較介面只顯示當前語言，避免版面被撐開。
