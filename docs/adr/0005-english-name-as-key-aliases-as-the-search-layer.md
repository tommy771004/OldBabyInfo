# 零件主鍵採來源穩定 ID，多語與俗稱走 Alias 層

同一支零件在台灣現場至少有四個名字：官方英文、日文原名、不一致的中文譯名、以及玩家口語俗稱；而使用者搜尋時打的往往是最後一種。名稱會更正，也可能在不同市場重複，因此不能充當資料主鍵。Part 的 `id` 採官方 App MasterData 的穩定 `group_id`；未匹配 MasterData 時才使用正規化來源鍵。三語名稱各存一欄，其餘有來源依據的寫法收進 Alias 供搜尋命中。

## Consequences

- 主要顯示名稱選 TAKARA TOMY 而非 Hasbro 命名，因為台灣流通的是日版。Hasbro 名稱一律收進 Alias，不影響主鍵。
- URL slug 仍由顯示名稱產生，只負責可讀路由；資料關聯一律使用 `id`，不得依賴 slug 或名稱。
- 名稱修正不得改動已存在的 MasterData `group_id`。
- 中文名取自台灣社群既有的通行用語，不自創翻譯——使用者搜尋的就是那些既有詞彙。
- 介面語言可在 zh-TW / ja / en 之間切換，但搜尋永遠跨語言全命中，不受當前介面語言限制。
- 三語並列僅出現在 Part 詳情頁；列表與比較介面只顯示當前語言，避免版面被撐開。
