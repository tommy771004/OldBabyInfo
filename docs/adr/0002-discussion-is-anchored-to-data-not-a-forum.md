# 討論錨定於資料實體，不做獨立論壇

新站開設獨立討論板必然面對冷啟動：使用者點進去看到空白的板，就再也不回來，而那個空頁面正好座落在全站視覺投資最重的地方。因此本站不設板塊，每則 Thread 都必須錨定一個 Subject（Part、Combo 或 Event），並以「全站最新討論」聚合頁作為入口。

## Considered Options

- **傳統分板論壇**——玩家最熟悉，但要正面承受冷啟動，且與「查詢工具」的定位互相拉扯。
- **單一時間軸**——內容不會沉澱成可查詢的資產。

## Consequences

- 沒有閒聊區。想討論與特定資料無關的話題的人，本站不服務，這是刻意的取捨。
- 討論內容會直接增加每個 Part 頁面的資訊價值與 SEO 權重，成為聚合站無法複製的部分。
