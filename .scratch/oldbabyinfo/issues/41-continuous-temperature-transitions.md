# 41 — 全站連續色溫過渡與段落銜接

**What to build:** 從首頁一路捲到頁尾，顏色像同一個空間的光線在變化，而不是好幾張底色拼在一起。

**Blocked by:** 05, 39

**Status:** done

落實 ADR-0006 的「連續過渡」約束。

- [x] 逐一檢查每個段落交界，確認無硬色邊
- [x] 深端與暖端之間的過渡發生在足夠長的距離上，不是一條分界線
- [x] 大面積色彩轉換帶有細微顆粒，無條帶狀斷階
- [x] 顆粒位於內容之下，不覆蓋文字與圖示
- [x] 各頁面之間的色溫銜接一致，跨頁瀏覽不出現突兀跳色

## Comments

05 號票用 Playwright 實測（不是憑肉眼）發現：色階中段（約 50%–60%）是中等亮度，深墨淺墨疊上去都過不了 WCAG AA，細節與示範見 ADR-0008、`/color-demo`。這張票逐一檢查段落交界時，凡是內容跨過這個中段區域（例如一個很長的過渡段落），必須確認該區段本身沒有放置需要可讀性的文字，或另外加襯底處理對比——不能只靠目視巡過去，建議用 `scripts/screenshot.mjs` 截圖後放大檢查，或重跑 05 號票的量測方法。

**做法：每個段落自己的背景就是一段漸層，不是實色。** 首屏（深場地色）→零件區→賽事區，三段
背景各自是 `linear-gradient`，且每一段的邊緣顏色精準銜接下一段的起點顏色——`.partsSection`
從 `surface-900`（銜接首屏底部）漸變到 `surface-700`（銜接賽事區頂部），`.eventsSection` 從
`surface-700` 漸變到 `surface-600`。這三段全程只在色階 0–40%（surface-950 到 surface-600）
之間走動，完全落在 ADR-0008 量出的深墨安全區（0–45%）內，不會碰到中段禁字帶。

**真正需要跨越中段禁字帶的只有一處：賽事區到頁尾之間，新增一個專門的 `.transitionBand`
空白區塊**（`clamp(18rem, 32vw, 26rem)`，約 288–416px 高——是一段真實距離，不是一條分界
線），背景漸層從 `surface-600` 一路走過 `surface-500`／`400`／`300`／`200` 到
`surface-100`，中間完整穿越中段禁字帶。這個區塊 `aria-hidden` 且不放任何文字或連結，正是
ADR-0008 明文允許的用法（「背景可以連續漸變，但可讀內容不能疊在漸層的正中段」）。

**顆粒：** `colors.css` 新增 `--grain`，一個用 `feTurbulence` 產生的細白噪點 SVG data URI，
只帶透明度（無色相），用第二層 `background-image` 疊在每個漸層背景之上——不用額外的
z-index 元素，因為 `background-image` 天生就在該元素自己的文字內容之下，天然滿足「顆粒位於
內容之下」。

**不是只看命名色階，是逐點量測實際插值後的對比度**（複用票 05 的方法）：寫了一個腳本，以
1% 為步進沿每段漸層取樣，計算每一點相對 `ink-on-dark`／`ink-on-light` 的真實 WCAG 對比度。
結果：首屏／零件區／賽事區三段的最低對比度分別是 15.28／10.57／7.62，全部遠高於 AA
門檻 4.5；文字實際落點（用 Playwright 量出每個連結／標題的真實像素座標，換算成該段漸層的
相對位置）落在 16–85% 之間，全部在安全平台上，沒有一處踩進過渡邊緣。`transitionBand`
本身量出最低對比度只有 2.17（因為它兩端都很深），但這個數字只是佐證「這裡确實不能放
文字」——它本來就沒有任何文字，不是違規。

**跨頁色溫銜接：** 把 `colors.css` 原本標記為「interim」的全站預設（`body` 深場地色）換成
暖端 `surface-100`／`ink-on-light`／`accent-on-light`——現在 `/parts`、`/events`、以及三個
內部 QA 頁（`/styleguide`、`/color-demo`、`/stadium-demo`）全部預設落在暖端，與首頁頁尾的
`surface-100` 完全同色。首頁的 `.hero` 仍在自己身上覆寫回深場地色（自成一體，不受這次全站
預設異動影響），零件區／賽事區也都各自明訂顏色，不吃全站預設，所以這次改動只實際影響了
先前「沒有自己顏色、單純繼承全站預設」的那幾個頁面——正是它們原本呈現生硬全黑、與首頁頁尾
完全不連續的地方。截圖比對：從首頁頁尾點連結進 `/parts` 或 `/events`，落地時的背景色與剛剛
看到的頁尾一模一樣，不再是黑底重置。

**範圍界線：** 這張票只處理色彩連續性，沒有動 `/parts`、`/events` 本身的版面（表格仍是無
padding 的陽春排版）——那是既有、獨立於本票之外的問題，不在「色溫過渡」的票面範圍內。

**Pipeline：** `npm run typecheck`、`npm run lint`、`npx vitest run`（116/116）、
`npm run build` 全數通過；`next start` 起正式伺服器後用 Playwright 截圖驗證首頁全頁連續
漸層（zh-TW 桌面版、手機 390px）、`/parts`、`/events`、`/styleguide`、`/color-demo` 在新的
全站配色下均正常無迴歸；並用獨立腳本重跑逐點對比度量測，取代單純目視巡查。
