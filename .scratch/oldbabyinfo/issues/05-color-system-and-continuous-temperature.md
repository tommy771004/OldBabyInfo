# 05 — 色彩系統與連續色溫過渡

**What to build:** 一套色彩 token，能同時表達「場上」的深色高能與「場邊」的溫暖易讀，且兩端之間的過渡是連續的，任何段落交界都不出現硬色邊。

**Blocked by:** 02

**Status:** ready-for-agent

落實 ADR-0006。

- [ ] 定義單一調色盤，深場地端與暖閱讀端是同一系統的兩端而非兩組配色
- [ ] 暖端色彩由場地色系推導，明確不使用米白、燕麥或通用編輯風背景
- [ ] 提供一個示範頁面，從深端捲動至暖端，目視確認沒有任何硬色邊
- [ ] 所有文字與其背景的對比度通過 WCAG AA
- [ ] token 以 CSS 變數實作，深暖兩端可被任何元件取用
