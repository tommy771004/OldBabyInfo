# 07 — 競技場俯視 SVG（signature artifact 本體）

**What to build:** 本站的招牌視覺物件——一個精細手繪的俯視競技場圓盤，具備同心衝擊區、脊線與發射位，足以單獨撐起首屏。

**Blocked by:** 02

**Status:** ready-for-agent

這是 ADR-0006 所稱「一個世界」的核心物件，其幾何語彙後續會被全站重複使用。

- [ ] 以手繪向量完成，非 CSS 圖形拼湊
- [ ] 同心圓、脊線、發射位等結構清晰可辨，具真實的場地資訊而非裝飾圖案
- [ ] 不使用發光、漸層填充或粒子
- [ ] 於各主要斷點下皆完整可見，不被容器裁切
- [ ] 匯出其幾何常數（半徑比例、角度）供後續元件沿用，確保全站幾何一致

## Comments

05 號票（色彩系統）實測發現：疊在 `/color-demo` 那組漸層背景中段（色階約 50%–60%）的文字，深墨淺墨都過不了 WCAG AA，細節見 ADR-0008。這個 SVG signature 若疊加在首頁漸層背景之上，要避開那個中段區域放置任何需要可讀性的文字或標註，或另外處理對比。
