# 06 — 字體管線：拉丁 display 定案 + 台北黑體 subset + 芫荽

**What to build:** 全站的字體系統就位，且中文字型不會拖垮首屏——數值與標題有明確個性，中文好讀，載入量受控。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 至少三款拉丁 display 候選實際 render 成對照圖供人挑選，不憑名稱決定
- [ ] 選定字型自託管，且不屬於 Google Fonts 常見輪替名單
- [ ] 數值字符（四維、百分比、樣本數）在候選比較中特別檢視，因為它們是全站最高頻的字符
- [ ] 台北黑體以 woff2 subset + `unicode-range` 分割載入
- [ ] 芫荽僅套用於少量點綴（引言、資料來源註記），不用於介面主體
- [ ] 首屏字型傳輸量有實測數字並記錄；無 FOIT，字體交換不造成明顯位移
