# 31 — Event 模型 + 手動種子 + 賽事行事曆

**What to build:** 玩家能查到近期有哪些賽事、在哪裡、什麼層級，不必翻遍社群貼文。

**Blocked by:** 03, 09

**Status:** ready-for-agent

刻意不阻塞於自動抓取管線——先以手動種子做出可用頁面，自動化另行處理。

- [ ] Event 資料模型就位，含日期、地點、Event Tier 與參賽結果
- [ ] 以手動種子資料填入足以驗收頁面的賽事筆數
- [ ] 行事曆頁區分即將舉行與已結束，過期場次不佔據主要版面
- [ ] Event Tier 的呈現不使用色塊膠囊標籤
- [ ] 近期無賽事時的狀態經過設計
