# 37 — 新手指南內容管線與版式

**What to build:** 一套長文內容的呈現方式，讓新手指南讀起來舒服，且日後新增文章不必再處理版式。

**Blocked by:** 08

**Status:** ready-for-agent

內容頁位於 ADR-0006 所稱「場邊」，採暖端色溫與最低動效強度。

- [ ] 內容以 Markdown 或 MDX 撰寫，新增文章不需改動程式
- [ ] 內文版式定案：行長、行高、標題層級、圖說、引言
- [ ] 引言與資料來源註記使用芫荽，其餘為台北黑體
- [ ] 具備目錄與段落錨點，長文可跳轉
- [ ] 中文標點與換行處理正確，無孤字與不當斷行
