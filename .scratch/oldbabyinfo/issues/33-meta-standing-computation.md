# 33 — Meta Standing 統計計算 + 測試

**What to build:** 一組由實際 Event 結果算出的 Combo 表現數據：使用率、前八強佔比、奪冠次數，並帶有樣本數與統計期間。

**Blocked by:** 03, 31

**Status:** ready-for-agent

落實 ADR-0003：本站不發布主觀強度分級。

- [ ] 明確定義統計口徑：前八強佔比的分母、統計期間的界定
- [ ] 明確定義 Combo 的同一性判準——微幅差異算同一組還是不同組
- [ ] 每筆結果附帶 Sample Size 與統計期間
- [ ] Sample Size 低於門檻時回傳「資料不足」狀態，而非名次
- [ ] 以固定的測試資料集覆蓋計算邏輯，含樣本不足的情境

## Comments

03 號票的 spike 實測：現有賽事資料裡，使用率有 1215 筆真實紀錄可用，但全年只有一場賽事留下完整名次（見 ADR-0003 更新）。意味著測試資料集必須把「樣本不足」當成**主要情境**準備，不是邊角案例——上線初期前八強佔比／奪冠次數幾乎每筆都會落在這個分支。

**31 號票的 Event 種子資料再次確認這個現實**：767 筆真實 G3 賽事場次，`results` 全部是 `null`。且 31 號票的種子資料**只有 G3 一個層級**（官方或更高層級賽事沒有對應的公開排程資料源）——這張票設計統計口徑時，「統計期間」與「樣本數」的計算範圍現階段等同於「G3 門市賽事範圍」，不是全賽事層級的完整圖像，這點在畫面文案上也該誠實反映。
