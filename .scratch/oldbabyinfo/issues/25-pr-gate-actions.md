# 25 — 慢資料 PR gate Actions + diff 可讀性

**What to build:** 排程抓取完成後自動開啟一個 Pull Request，讓你在 30 秒內看懂資料變了什麼並決定是否接受。

**Blocked by:** 01, 24

**Status:** ready-for-agent

落實 ADR-0004 的核心設計：機器做苦工，人做核可。

- [ ] 排程執行後自動建立 PR，標題與內文摘要本次變動
- [ ] PR 內文以人類可讀的形式列出變動摘要，例如某零件的某項 Stat 由多少變為多少
- [ ] Needs Review 的項目在 PR 內文中明確突出，並附上兩個模型的分歧結果
- [ ] 無變動時不建立 PR，避免噪音
- [ ] 既有 PR 尚未合併時更新該 PR 而非另開一個
- [ ] 合併後自動觸發部署
