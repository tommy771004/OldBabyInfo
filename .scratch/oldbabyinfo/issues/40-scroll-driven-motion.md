# 40 — 捲動驅動旋轉與互動動效

**What to build:** 網站動起來——競技場隨捲動旋轉，互動有回應，而且動的都是本來就看得見的東西。

**Blocked by:** 39

**Status:** ready-for-agent

熱血來自旋轉、離心與碰撞的真實物理，不來自發光與粒子。

- [ ] 競技場旋轉綁定捲動位置，非自動播放
- [ ] 動效不改變任何內容的可見性；關閉 JavaScript 後頁面內容完全不變
- [ ] 尊重 `prefers-reduced-motion`，該設定下動效停止而內容不受影響
- [ ] 按鈕不使用滑入時上浮或放大的效果
- [ ] 不使用生長式底線動畫
- [ ] 動效在中階裝置上維持流暢，不造成捲動掉幀
