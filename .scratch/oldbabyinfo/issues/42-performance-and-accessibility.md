# 42 — 效能與可及性

**What to build:** 網站在真實裝置與真實網路下開得快、用得動，鍵盤與螢幕閱讀器都能操作。

**Blocked by:** 16, 22, 39

**Status:** ready-for-agent

- [x] 中文字型 subset 實際生效，首屏字型傳輸量有實測數字
- [x] 無版面位移：圖片與字體載入不造成內容跳動
- [x] 全站可純鍵盤操作，焦點指示清晰可見
- [x] 比較器、建構器、搜尋與篩選皆可由螢幕閱讀器理解
- [x] 所有文字對背景通過 WCAG AA；填色按鈕上的文字對比尤其檢查
- [x] 每一個看起來可互動的元素都真的可互動，並經實際點擊驗證
