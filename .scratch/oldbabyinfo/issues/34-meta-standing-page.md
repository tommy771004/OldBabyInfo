# 34 — 勝率榜頁面

**What to build:** 玩家能看到哪些 Combo 真的在贏，以及這個結論建立在多少場比賽之上。

**Blocked by:** 33, 13

**Status:** ready-for-agent

- [ ] 呈現使用率、前八強佔比與奪冠次數
- [ ] Sample Size 與統計期間與數據同等顯眼，不是小字附註
- [ ] 樣本不足時明確顯示「資料不足」並說明筆數，不勉強排名
- [ ] 每個 Combo 可展開查看其組成零件，並連向各 Part 詳情頁
- [ ] 頁面明確說明本站不發布主觀強度分級，數據來源可追溯
- [ ] 不使用 S／A／B 之類的分級標記

## Comments

03 號票的 spike 實測：上線初期，使用率會有真實數字，但前八強佔比／奪冠次數幾乎每個 Combo 都會顯示「資料不足」（全年只有一場賽事留下完整名次）。設計驗收畫面時，「資料不足」狀態不是次要的空狀態，是**多數 Combo 的常態**，要當主要情境設計，不能只當 edge case 補一句文字。
