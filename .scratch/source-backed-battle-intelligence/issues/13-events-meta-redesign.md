# 13 — Events 與 Meta 工作流改版

**What to build:** 使用者能在同一設計語言中查找 Event，並以期間與 Sample Size 正確解讀 Meta Standing。

**Blocked by:** 01 — 首頁對戰搜尋與視覺基座；07 — 原始 Event 試算表每日更新

**Status:** ready-for-agent

- [ ] Event 清單以日期、地點、層級與報名方式為主要掃描軸
- [ ] 每筆 Event 清楚連回原始來源
- [ ] Meta Standing 顯示統計期間、Sample Size、使用率、前八佔比與冠軍次數
- [ ] 樣本不足時顯示資料不足，不產生誤導排名
- [ ] Meta Standing 與 Tier Assessment 的命名、版型與說明明確不同
- [ ] 兩個頁面沿用暖鐵／陶土色階、字體與互動語言
- [ ] 手機版日期與主要資訊先出現，不讓次要欄位推擠
- [ ] 測試涵蓋 upcoming／past、空 Event、樣本不足與正常排名
