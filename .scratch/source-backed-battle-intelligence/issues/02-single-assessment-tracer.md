# 02 — 單一 Part Assessment tracer

**What to build:** 從一份可重現的來源輸入，到靜態資料與 Part 頁，完整發布一筆可追溯的 Assessment。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] Assessment 可附著到一個 Part 或 Combo
- [ ] Assessment 支援 Tier、推薦 Combo、打法、重量與 Mold 觀察類型
- [ ] 每筆 Assessment 保留 Source Excerpt、Discovery Source、時間與 Attribution Status
- [ ] 有 Evidence Source 時可定位原作者及原始 LINE／影片
- [ ] 無 Evidence Source 時資料仍可發布並顯示「未附原始來源」
- [ ] 同一份輸入重跑不產生重複項目或不穩定排序
- [ ] 從來源 fixture 到公開頁面的最高層測試通過
