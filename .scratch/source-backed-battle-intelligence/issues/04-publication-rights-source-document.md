# 04 — Publication Rights 與 Source Document

**What to build:** 使用者可閱讀具公開權利的來源全文；沒有 Publication Rights 的輸入只能留下合法的結構化事實、必要短片段與原文連結。

**Blocked by:** 02 — 單一 Part Assessment tracer

**Status:** ready-for-agent

- [ ] Source Document 記錄標題、發布者、發布／抓取時間、canonical URL 與完整內容
- [ ] 每份 Source Document 記錄授權名稱、授權頁面或明確許可證明
- [ ] 缺少 Publication Rights 時拒絕發布全文
- [ ] 全文被拒絕時，合法的結構化事實與必要短片段可獨立處理
- [ ] Assessment 可連回 Source Document 或 Discovery Source
- [ ] Source Document 頁清楚顯示授權、原文連結與抓取時間
- [ ] 權利撤回時可移除全文而不破壞其他領域資料
- [ ] 測試涵蓋允許、拒絕與撤回三種公開行為
